# 库存管理系统云部署操作指南

## 📋 准备工作

### 1. 注册账号
- [GitHub](https://github.com) - 代码托管
- [Vercel](https://vercel.com) - 前后端部署
- [Supabase](https://supabase.com) - PostgreSQL 数据库
- [阿里云](https://www.aliyun.com) - OSS 对象存储

### 2. 创建项目

#### GitHub 仓库
```bash
# 1. 在 GitHub 创建新仓库：inventory-system
# 2. 克隆到本地
git clone https://github.com/yourusername/inventory-system.git
cd inventory-system

# 3. 复制项目文件
cp -r /Users/wy/data/doc/inventory-system/* .

# 4. 提交代码
git add .
git commit -m "Initial commit: inventory management system"
git push origin main
```

#### Supabase 项目
1. 登录 [Supabase Dashboard](https://app.supabase.com)
2. 创建新项目：`inventory-system`
3. 获取连接信息：
   - Project URL (SUPABASE_HOST)
   - Database Password (SUPABASE_PASSWORD)
   - API Key (SUPABASE_JWT_SECRET)

#### 阿里云 OSS
1. 登录 [阿里云控制台](https://oss.console.aliyun.com)
2. 创建 Bucket：`inventory-system-files`
3. 获取 AccessKey：
   - AccessKey ID
   - AccessKey Secret
4. 记录 Endpoint：`https://oss-cn-hangzhou.aliyuncs.com`

### 第二步：部署后端到 Vercel

```bash
# 1. 进入后端目录
cd backend

# 2. 安装 Vercel CLI
npm i -g vercel

# 3. 登录 Vercel
vercel login

# 4. 链接项目
vercel link

# 5. 配置环境变量
vercel env add SUPABASE_HOST
vercel env add SUPABASE_PORT
vercel env add SUPABASE_USER
vercel env add SUPABASE_PASSWORD
vercel env add SUPABASE_DB_NAME
vercel env add SUPABASE_JWT_SECRET
vercel env add OSS_ENDPOINT
vercel env add OSS_ACCESS_KEY_ID
vercel env add OSS_ACCESS_KEY_SECRET
vercel env add OSS_BUCKET_NAME
vercel env add OSS_BUCKET_DOMAIN

# 6. 部署
vercel --prod
```

### 第三步：部署前端到 Vercel

```bash
# 1. 进入前端目录
cd frontend

# 2. 链接项目
vercel link

# 3. 配置环境变量
vercel env add NEXT_PUBLIC_API_URL
vercel env add NEXT_PUBLIC_OSS_URL

# 4. 部署
vercel --prod
```

## 🚨 故障排除

### 常见问题

1. **数据库连接失败**
   - 检查 Supabase 连接信息
   - 确认网络访问权限

2. **文件上传失败**
   - 检查 OSS 配置
   - 确认 Bucket 权限

3. **API 调用超时**
   - 检查 Vercel 函数日志
   - 优化数据库查询

4. **前端无法访问后端**
   - 检查 CORS 配置
   - 确认环境变量设置

### 回滚策略
```bash
# 回滚到上一个版本
vercel rollback --scope=project-name
```
