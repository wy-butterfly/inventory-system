# 库存管理系统云部署方案

## 部署架构

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   GitHub    │───▶│   Vercel    │───▶│  Supabase   │
│   源码仓库   │    │   前端部署   │    │ PostgreSQL  │
└─────────────┘    └─────────────┘    └─────────────┘
                           │
                           ▼
                   ┌─────────────┐
                   │   Vercel    │
                   │   后端 API   │
                   └─────────────┘
                           │
                           ▼
                   ┌─────────────┐
                   │  阿里云 OSS  │
                   │  文件存储    │
                   └─────────────┘
```

## 适配方案

### 1. 前端部署 (Vercel)
- ✅ 无需修改，直接部署
- ✅ Next.js 14 原生支持
- ✅ 自动优化和 CDN

### 2. 后端部署 (Vercel Serverless)
- 🔄 修改为 Serverless Functions
- 🔄 适配 Supabase 连接
- 🔄 适配阿里云 OSS

### 3. 数据库 (Supabase PostgreSQL)
- 🔄 替换 MySQL 连接
- 🔄 修改 SQL 语法兼容 PostgreSQL
- 🔄 配置连接池

### 4. 文件存储 (阿里云 OSS)
- 🔄 替换本地文件存储
- 🔄 实现 OSS 上传/下载
- 🔄 配置 CDN 加速

## 操作步骤

### 第一阶段：环境准备
1. 注册并配置 Supabase 项目
2. 注册阿里云 OSS 并创建 Bucket
3. 创建 GitHub 仓库
4. 配置 Vercel 项目

### 第二阶段：代码适配
1. 修改后端数据库连接
2. 实现 OSS 文件存储
3. 适配 Vercel Serverless
4. 更新前端 API 配置

### 第三阶段：部署上线
1. 推送代码到 GitHub
2. 配置 Vercel 环境变量
3. 执行数据库迁移
4. 测试完整功能

## 成本估算

| 服务 | 免费额度 | 超出费用 |
|------|----------|----------|
| Vercel (前端) | 100GB 带宽/月 | $20/100GB |
| Vercel (后端) | 10万函数调用/月 | $0.30/万次 |
| Supabase | 500MB 数据库 | $25/GB |
| 阿里云 OSS | 5GB 存储 | ¥0.12/GB/月 |

**预估月费用**：免费额度内完全免费，超出后约 ¥30-50/月

## 优势

1. **零运维**：全托管服务，无需服务器维护
2. **自动扩缩**：根据访问量自动调整资源
3. **全球加速**：Vercel CDN + OSS CDN
4. **数据安全**：Supabase 自动备份
5. **成本可控**：按使用量付费，免费额度充足

## 注意事项

1. **冷启动**：Serverless 函数首次调用有 1-2 秒延迟
2. **执行时间**：Vercel 函数最长执行 10 秒
3. **文件大小**：单次上传限制 4.5MB
4. **并发限制**：免费版 1000 并发连接
