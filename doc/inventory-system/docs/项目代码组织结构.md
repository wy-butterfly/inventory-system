### 2.2 各层职责说明

```
一个请求的完整处理流程（以"新增库存"为例）：

1. 用户在前端填写表单，点击"提交"
2. 前端发送 POST /api/v1/inventories 请求到后端

3. [Router] router.go 匹配到路径 /api/v1/inventories，
   确定由 inventory_handler.go 的 Create 函数处理

4. [Middleware] 请求先经过中间件链：
   → cors.go：允许跨域
   → logger.go：记录请求日志
   → auth.go：验证JWT Token，提取用户信息
   → permission.go：检查用户角色是否有"新增"权限

5. [Handler] inventory_handler.go → Create()
   → 解析请求体中的JSON数据（对应 dto/request/inventory_req.go 定义的结构）
   → 调用参数校验
   → 调用 Service 层

6. [Service] inventory_service.go → CreateInventory()
   → 检查物料编码是否已存在（调用 Repository）
   → 组装数据模型（model/inventory.go）
   → 调用 Repository 保存数据
   → 记录操作日志

7. [Repository] inventory_repo.go → Create()
   → 使用 GORM 将数据插入 MySQL 的 inventories 表

8. [Handler] 获取到 Service 返回的结果
   → 组装响应数据（dto/response/inventory_resp.go）
   → 使用 pkg/response 返回统一格式的JSON
```

### 3.2 各层职责说明

```
一个用户操作的完整前端处理流程（以"查看库存列表"为例）：

1. 用户在浏览器访问 /inventory

2. [路由] Next.js 根据 URL 匹配到 src/app/(portal)/inventory/page.tsx

3. [页面] page.tsx 渲染页面结构：
   → 使用 <InventoryFilter /> 展示筛选条件
   → 使用 <InventoryTable /> 展示数据表格

4. [Hook] InventoryTable 组件内部使用 useInventory() hook：
   → hook 调用 inventoryService.getList(params) 发起请求

5. [Service] inventoryService.ts → getList()
   → 使用 lib/api.ts 创建的 Axios 实例发送 GET /api/v1/inventories?page=1&size=20
   → Axios 自动在请求头加上 Authorization: Bearer <token>

6. [后端响应] 后端返回 JSON 数据

7. [Hook] useInventory() 接收到数据，更新组件状态

8. [组件] InventoryTable 重新渲染，表格显示库存数据
```

## 6. 文件命名规范

### 6.1 后端 (Go)

| 类型 | 命名方式 | 示例 |
|------|----------|------|
| 文件名 | snake_case（下划线分隔） | `inventory_handler.go` |
| 包名 | 小写单词 | `handler`, `service`, `model` |
| 结构体/接口 | PascalCase（大驼峰） | `InventoryService`, `CreateInventoryReq` |
| 函数名 | PascalCase（导出）/ camelCase（未导出） | `CreateInventory()`, `validateCode()` |
| 常量 | PascalCase 或全大写 | `MaxFileSize`, `STATUS_ACTIVE` |

### 6.2 前端 (TypeScript/React)

| 类型 | 命名方式 | 示例 |
|------|----------|------|
| 组件文件 | PascalCase（大驼峰） | `InventoryTable.tsx` |
| 工具/服务文件 | camelCase（小驼峰） | `inventoryService.ts`, `useAuth.ts` |
| 类型文件 | camelCase | `inventory.ts` |
| CSS类名 | TailwindCSS工具类 | `className="flex items-center gap-2"` |
| 组件名 | PascalCase | `export function InventoryTable() {}` |
| 函数/变量 | camelCase | `const inventoryList = ...` |
| 常量 | UPPER_SNAKE_CASE | `const MAX_FILE_SIZE = 20 * 1024 * 1024` |
| 类型/接口 | PascalCase | `interface Inventory {}` |

### 6.3 数据库

| 类型 | 命名方式 | 示例 |
|------|----------|------|
| 表名 | snake_case 复数 | `inventories`, `operation_logs` |
| 字段名 | snake_case | `material_code`, `created_at` |
| 索引名 | `idx_表名_字段名` | `idx_inventories_material_code` |
